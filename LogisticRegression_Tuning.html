⚙️ จูนพารามิเตอร์ Logistic Regression

เบื้องหลังของ Logistic Regression คือสมการความน่าจะเป็น $P(y=1|X) = \frac{1}{1 + e^{-(w \cdot x + b)}}$
ลองปรับค่า C และ Penalty เพื่อดูว่ามันส่งผลต่อ "เส้นแบ่งความน่าจะเป็น (Decision Boundary)" แบบ 2 มิติอย่างไร!
1. C (Inverse Regularization) ปานกลาง (1.0)
ความ "บ้าจี้" ของโมเดล:
- C ต่ำ: ดื้อรั้น! ลากเส้นแบ่งตามภาพรวม ไม่สนข้อมูลแปลกแยก (ป้องกัน Overfitting)
- C สูง: บ้าจี้! พยายามบิดเส้นเอียงไปมา เพื่อให้ทายถูกทุกจุดแม้กระทั่งจุดขยะ (ระวัง Overfitting)
2. Penalty (การลงโทษ)
วิธีกำจัดตัวแปร:
- L2 (Ridge): ใช้งานตัวแปรทุกตัวร่วมกัน (เส้นแบ่งเฉียงตามปกติ)
- L1 (Lasso): เด็ดขาด! ถ้าตัวแปรไหนดูไม่ค่อยเกี่ยว มันจะตัดทิ้งเป็น 0 ทันที (เส้นแบ่งจะตั้งฉาก หรือขนานแกน)
