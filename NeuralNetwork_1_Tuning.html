🧠 ห้องแล็บปรับจูน Neural Network

จำลองการปรับแต่ง โครงสร้างสมอง และ เทคนิคการเรียนรู้
เป้าหมายของคุณคือการกด "เริ่มฝึก (Train)" และทำให้กราฟ Loss (ความผิดพลาด) ลดลงสู่ 0 ให้เร็วและนิ่งที่สุด!

📖 คำศัพท์ที่ควรรู้

1. Perceptron & MLP
Perceptron: คือเซลล์สมอง 1 เซลล์ (หรือพนักงาน 1 คน)
MLP (Multilayer Perceptron): การเอาเซลล์มาต่อกันเป็นชั้นๆ (Layer) ชั้นซ่อนเร้น (Hidden) ยิ่งเยอะยิ่งคิดซับซ้อนได้
2. Forward & Backpropagation
Forward Prop: ข้อมูลวิ่งจากซ้ายไปขวา เพื่อเดาคำตอบ
Backprop: พอรู้ว่าเดาผิด จะส่งข้อความด่าย้อนกลับจากขวามาซ้าย เพื่อบอกให้พนักงานปรับแก้ค่าน้ำหนัก (Weights)
3. Loss Function
เครื่องวัดความห่วยแตก! ยิ่ง Loss สูงแปลว่า AI ทายผิดเยอะ เป้าหมายของการฝึกคือการทำยังไงก็ได้ให้ Loss เข้าใกล้ 0
4. Softmax (Output)
ฟังก์ชันที่อยู่ชั้นสุดท้ายเสมอ ทำหน้าที่แปลงคะแนนดิบๆ ให้กลายเป็น "เปอร์เซ็นต์ความน่าจะเป็น (%)" ที่รวมกันได้ 100 พอดี

⚙️ ปรับจูนพารามิเตอร์

โครงสร้าง (Architecture)
ขนาดความลึกและกว้างของ MLP
Activation Function
กฎการกรองสัญญาณของพนักงานแต่ละคน
Optimizer & Gradient Descent
Gradient Descent: การก้าวเดินลงเขาเพื่อหาจุดผิดพลาดต่ำสุด
Optimizer: วิธีการก้าวเดิน (SGD = เดินธรรมดา, Adam = มีเข็มทิศอัจฉริยะ)
