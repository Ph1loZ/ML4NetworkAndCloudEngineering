📐 จูนพารามิเตอร์ SVM (Support Vector Machine)

ทดลองปรับค่า Kernel, C และ Gamma แล้วสังเกตว่า "เส้นแบ่งอาณาเขต (Decision Boundary)" เปลี่ยนรูปร่างไปอย่างไร
เป้าหมายคือการสร้างเส้นแบ่งที่คลุมข้อมูลสีแดงได้หมด โดยไม่คดเคี้ยวหรือซับซ้อนจนเกินไป (หลีกเลี่ยง Overfitting)

⚙️ ตัวแปร (Hyperparameters)

1. Kernel (รูปแบบของเส้นแบ่ง)
มิติของการมองปัญหา:
- Linear: ลากเส้นตรงทื่อๆ (เหมาะกับปัญหาพื้นฐาน)
- RBF (Radial Basis Function): เส้นโค้งอิสระ วงกลมล้อมรอบข้อมูล (เก่งมากและนิยมใช้ที่สุด)
2. C (Regularization) ต่ำ (ยอมให้มีข้อผิดพลาดได้)
ความเข้มงวดของกฎ:
- ค่า C ต่ำ: อนุโลมให้มีจุดขยะ (Noise) หลุดเข้ามาได้บ้าง เพื่อให้เส้นแบ่งดูเรียบง่ายสมูท (Generalized)
- ค่า C สูง: เข้มงวดมาก! ต้องไม่ให้มีใครผิดกลุ่มเลย เส้นแบ่งจะบิดเบี้ยวเพื่อหลบจุดขยะ (เสี่ยง Overfitting)
3. Gamma (สำหรับ RBF Kernel) ปานกลาง
ระยะสายตาของจุดข้อมูล (ขอบเขตอิทธิพล):
- Gamma ต่ำ: สายตายาว มองเห็นกันไกลๆ (อาณาเขตกว้างขวางและเชื่อมต่อกัน)
- Gamma สูง: สายตาสั้น สนใจแค่จุดที่อยู่ติดกันมากๆ (อาณาเขตจะหดแคบเป็นเกาะเล็กเกาะน้อยรอบจุดข้อมูล)
