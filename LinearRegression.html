📈 Linear Regression: สร้างเส้นพยากรณ์ Cloud Load

สมมติว่าเรามีข้อมูลการใช้งาน Cloud Server จุดสีน้ำเงินคือ "ข้อมูลในอดีต" (ผู้ใช้ X คน ทำให้เกิดโหลด Y%)
เป้าหมายของคุณคือการปรับค่า ความชัน (W) และ จุดเริ่มต้น (b) เพื่อลากเส้นตรงที่ทายข้อมูลได้แม่นยำที่สุด (เกิด Error น้อยที่สุด)!
Load = (W × Users) + b
📐 ความชัน (W - Weight) 1.0
อัตราการเพิ่ม: ผู้ใช้เพิ่ม 1 คน โหลดเพิ่มกี่ %
🎯 จุดเริ่มต้น (b - Bias) 0
โหลดพื้นฐาน: ตอนที่ยังไม่มีผู้ใช้งานเลย (0 คน)
ระยะผิดพลาดรวม (Total Error) 0
เส้นสีแดงคือระยะความคลาดเคลื่อน
พยายามทำให้ตัวเลขนี้ ต่ำที่สุด!
💡 สิ่งที่คุณกำลังทำคือ "การเทรนโมเดล"
การที่คุณเลื่อนสไลเดอร์เพื่อหาค่า W และ b ที่ทำให้ Error ต่ำที่สุด นั่นคือกระบวนการเดียวกับที่ AI ทำเป๊ะๆ! (อัลกอริทึมนี้เรียกว่า Gradient Descent หรือ Least Squares)
จำนวนผู้ใช้งาน (Users) ➡️
