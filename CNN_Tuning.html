⚙️ จูนพารามิเตอร์ CNN (Convolutional Neural Network)

สิ่งที่กำหนดว่า "สมองส่วนวิเคราะห์ภาพ" จะทำงานอย่างไร ขึ้นอยู่กับ 3 พารามิเตอร์หลัก: Filter Size, Stride, และ Padding
ลองปรับค่าต่างๆ เพื่อดูว่า "ขนาดของภาพ" เปลี่ยนแปลงไปอย่างไรหลังจากการสแกน!
1. Filter Size (K)
ขนาดของแว่นขยาย:
- 3x3: มาตรฐานยอดฮิต เก็บรายละเอียดเล็กๆ ได้ดี
- 5x5: แว่นขยายใหญ่ขึ้น มองเห็นภาพรวมได้กว้างขึ้น
2. Stride (S)
ก้าวเดินของการสแกน:
- Stride = 1: ขยับทีละช่อง ค่อยๆ สแกน (ภาพ Output จะใหญ่)
- Stride = 2: ขยับกระโดดทีละ 2 ช่อง เพื่อย่อขนาดภาพให้เล็กลงเร็วๆ (ลดภาระคอมพิวเตอร์)
3. Padding (P)
การเสริมขอบภาพ:
- Valid (ไม่มีเสริมขอบ): สแกนเฉพาะพื้นที่ด้านใน ทำให้ข้อมูลตรงขอบภาพหายไป และภาพเล็กลง
- Same (เสริมขอบด้วย 0): เติมกรอบหลอกๆ เข้าไป เพื่อรักษาข้อมูลริมขอบภาพไว้
